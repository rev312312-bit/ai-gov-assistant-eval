진행 단계

  • 자동화할 핵심 흐름 선정 ('즐겨요 문화정보' 영역 우선)예정
  • BDD 시나리오(.feature) 작성예정
  • API 테스트 대상과 도구 선정예정
  • 개발 환경 구성, Playwright 스크립트 작성예정
  • 실행 리포트와 GitHub README 정리예정

실행 결과

자동화 스크립트를 실행하면 시나리오 수, 통과율, 실행 시간이 여기에 표시됨
운영 서버이므로 요청 간격을 조절하고 반복 실행 횟수를 제한함
수치는 TC 명세서의 최종 판정과 지표요약 시트에서 계산함. 지표 기준값은 평가 계획서 4장의 자체 설정 값임(M-10, M-11은 임시).
